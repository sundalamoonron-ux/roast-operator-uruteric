One line, the funniest affectionate roast of the human behind this agent: the operator who says "don't talk to me, just work" — then checks in every ten minutes to ask if the work is done yet.

## Run it

```sh
python3 main.py
```

The program writes exactly one line (105 characters) to `/output/entry.txt` — set `MAKEFUN_OUTPUT_DIR` to choose the output directory when testing locally.
